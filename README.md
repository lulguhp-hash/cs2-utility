# CS2 Utility — Telegram Mini App

Статический фронтенд для Telegram Mini App. Интерфейс адаптирован под мобильные устройства, подключает Telegram Web Apps SDK, содержит каталог карт, поиск, фильтры стороны/типа гранаты и избранное.

## Что уже работает
- Каталог карт: Dust2, Mirage, Inferno, Nuke, Ancient, Anubis, Overpass, Vertigo, Train.
- Поиск по каталогу.
- Фильтры по типу гранаты и стороне.
- Избранное в браузере пользователя.
- Экран отдельной карты и фильтр позиций.
- Telegram WebApp SDK: ready, expand, цвета интерфейса.

## Важно о наполнении базы
В `data.js` массив `lineups` намеренно пустой. Это не ошибка: для настоящих раскидок нужны проверенные данные — карта, сторона, тип гранаты, точка броска, положение прицела, способ броска, видео/изображение. Не следует выдавать выдуманные координаты за рабочие раскидки. Следующий этап — импорт/проверка материалов CS2Util и наполнение базы.

Пример структуры одной записи:
```js
{
  id: "dust2-a-long-smoke",
  map: "dust2",
  type: "smoke",       // smoke | flash | molotov | he
  side: "T",           // T | CT
  position: "A Long",
  name: "Название раскидки",
  notes: "Проверенная пошаговая инструкция",
  image: "assets/dust2-a-long-smoke.webp",
  video: ""
}
```

## Бесплатное размещение на GitHub Pages
1. Создай аккаунт на GitHub, если его ещё нет.
2. Создай публичный репозиторий, например `cs2-utility`.
3. Загрузи **содержимое** этой папки в корень репозитория (index.html должен лежать в корне).
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери Deploy from a branch → `main` → `/ (root)` → Save.
6. Подожди публикации. GitHub покажет HTTPS-адрес вида `https://ТВОЙ-ЛОГИН.github.io/cs2-utility/`.

## Подключение в BotFather
1. Открой @BotFather → выбери `@hae_flash_smoke_bot`.
2. Mini Apps → Main App → Enable/Configure (название пункта может немного отличаться).
3. Вставь HTTPS-адрес GitHub Pages и сохрани.
4. В Menu Button укажи тот же адрес, если хочешь отдельную кнопку меню.
5. Проверь запуск приложения в Telegram.

## Безопасность
- Не публикуй токен бота в репозитории, браузере или переписке.
- Для этого статического прототипа токен бота не нужен.
- Не добавляй токен в HTML/JavaScript. Если позже понадобится сервер и Bot API, токен хранится только в переменных окружения на сервере.
- Для production-авторизации Telegram `initData` нужно проверять на сервере. Клиентский `initDataUnsafe` не является доказательством подлинности пользователя.
